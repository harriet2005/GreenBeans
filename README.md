# 🌱 GreenBeans — Empowering Student Climate Action

**Team Name:** Campus Innovators  
**Project Title:** *GreenBeans — Protecting our planet is not just our job, it's our legacy*

GreenBeans is a web-based platform designed to help schools in Kenya organise, track, and showcase environmental activities. Inspired by the principles of Wangari Maathai, the platform promotes youth empowerment, community engagement, and meaningful participation in climate action.

## 🔗 Project Access

- 🌐 **Live Website:** [GreenBeans Website](https://greensbeans.netlify.app)  
- 📺 **Demo Video:** [YouTube Video](https://youtu.be/VJg2KCJgQAY)  
- 📊 **Pitch Deck (PPTX):** [GreenBeans Pitch Deck](https://github.com/harriet2005/GreenBeans/raw/main/public/GreenBeans_Pitch.pptx)

Students can join or connect with environmental clubs, participate in verified climate-action activities, and collaborate with partner organisations through weekly or monthly challenges.

Built with **React.js** (frontend) and **Supabase** (backend), GreenBeans offers a clean and user-friendly digital environment for managing green clubs, sharing achievements, and tracking real environmental impact.

---

## 🚨 Problem We Are Solving

Many Kenyan schools face challenges running student environmental clubs:

- Activities are unorganised and difficult to track.  
- Teachers handle everything manually, leading to administrative overload.  
- Students lack a central platform to showcase achievements or build environmental portfolios.  
- Schools have no unified system for organising or validating events like tree planting and clean-ups.  
- Existing efforts happen in silos with limited visibility or collaboration.

**Result:** Low participation, fragmented efforts, and weak long-term environmental impact.

---

## 🌿 Our Solution

GreenBeans provides a simple online platform for students and schools to organise, participate in, and showcase climate-action activities.

### The platform enables:

- **Club Management** — Create and organise environmental clubs with ease.  
- **Activity Tracking** — Log clean-ups, tree planting, workshops, and more.  
- **Media Feed** — Share photos and videos to build community engagement.  
- **Challenges & Competitions** — Boost participation with weekly/monthly challenges.  
- **Teacher Dashboard** — Monitor club progress and generate reports quickly.  
- **Student Profiles** — Build a personal environmental portfolio to showcase leadership and participation.

GreenBeans makes environmental action **organised, visible, and rewarding**.

## 💼 Business Model (Kenyan-Friendly)

GreenBeans is **free for students** to ensure inclusivity and high engagement.

The project sustains itself through:
- Partnerships with NGOs and environmental organisations  
- School subscriptions for advanced dashboards and analytics  
- Sponsored challenges and climate-action campaigns  

This model stays affordable and scalable within the Kenyan education ecosystem.

## 🛠 Getting Started (For Developers)

### Prerequisites
- **Node.js** (LTS recommended)  
- **Git**

### Installation

1. Clone the repository:
```bash
   git clone https://github.com/harriet2005/GreenBeans.git
   cd GreenBeans
```

2. Install frontend dependencies:
```bash
   npm install
```

3. Configure environment variables:
   Create `.env.local` and add:
```ini
   REACT_APP_SUPABASE_URL=your_supabase_url
   REACT_APP_SUPABASE_ANON_KEY=your_supabase_key
```

4. Start the development server:
```bash
   npm start
```

App runs at: http://localhost:3000
